# Підключення Orbit Display

## Майстер на Windows

**01 · З'єднання.** Для USB під'єднай кабель із передаванням даних. На Samsung: Налаштування → Про телефон → Відомості про ПЗ → натисни «Номер збірки» 7 разів. У параметрах розробника ввімкни «Налагодження через USB», розблокуй телефон і дозволь доступ ПК. Натисни «Перевірити USB» або «Далі»: програма сама створить тунель ADB. Без успішної перевірки USB майстер не переходить далі. Кабелі USB-A → USB-C також підходять. Після перепідключення перевірка потрібна знову; вона повторюється й перед запуском сеансу.

Для Wi-Fi обидва пристрої мають бути в одній мережі. Введи на телефоні одну з адрес ПК, показаних програмою, без порту. Дозволь Orbit у брандмауері для приватної мережі. USB-модем також працює як мережеве підключення, якщо прошивка телефона дозволяє доступ до ПК. Bluetooth не реалізований.

**02 · Екран.** Якщо додаткового монітора ще немає, натисни «Додати віртуальний монітор». У комплектному Virtual Driver Control встанови Virtual Display Driver та створи один монітор. Це може вимагати прав адміністратора й перезавантаження. У Windows вибери «Розширити ці дисплеї», повернися в Orbit та онови список. Вибери додатковий дисплей, 1920 × 1080, підтримувану частоту й положення ← ↑ ↓ →. «Далі» застосовує режим; помилка застосування не пропускає до наступного кроку. Для першого вибору пропонується Full HD, якщо драйвер його надає, і частота до 120 Гц. Вищі частоти можна обрати вручну.

Без віртуального монітора доступне дублювання основного екрана з окремим підтвердженням перед передаванням. APK сам не створює монітор Windows. Попередній режим додаткового дисплея відновлюється після нормального закриття Orbit. Після аварійного завершення його можна змінити в налаштуваннях Windows.

**03 · Якість.** Вибери Full HD, чіткість або легший потік. «Авто» обмежує ціль FPS частотою джерела та фактичною частотою Android. H.264 використовується за замовчуванням: NVIDIA NVENC → Intel Quick Sync → програмний x264; на Android — MediaCodec з перевагою апаратного декодера. Є окремі режими сумісності JPEG та захоплення GDI.

Якщо рух ривками, спробуй **1280 px + до 60 FPS**. Це знижує роздільність потоку, але зберігає розмір робочого столу Windows. Для дрібного тексту поверни Full HD. Якщо H.264 не запускається, зупини сеанс, повернися до якості й увімкни JPEG.

**04 · Запуск.** Натисни «Почати сеанс». На телефоні пройди його три кроки: спосіб з'єднання → підготовка ПК → код. Для USB адреса 127.0.0.1 визначається автоматично. Введи шестизначний код та при першому спарюванні звір чотири групи відбитка ПК. Код діє 10 хвилин для нового з'єднання; активний сеанс продовжується. Для завершення натисни «Зупинити сеанс» на ПК або × на телефоні.

## Керування та доступ

Один палець — вказівник/перетягування, два — прокрутка. «Текст» надсилає текст у активне вікно ПК. Меню ⋯ містить Enter, Esc, Tab, Ctrl+C/V, праву кнопку миші, повний екран та обмін текстом буфера. Буфер вимкнений до явного дозволу на ПК. Дотик і клавіатуру також можна вимкнути.

Трафік захищено TLS і прив'язкою до сертифіката ПК. Сервер USB слухає лише 127.0.0.1:48620; мережевий режим — TCP 48620. Звук, DRM-відео та захищений екран Windows/UAC не передаються. Згортання Android призупиняє сеанс.

## Якщо не підключається

- «Connection refused» у USB: перевір налагодження та дозвіл ПК на телефоні, натисни «Перевірити USB» на ПК й почни сеанс. Один під'єднаний Android за раз.
- Wi-Fi: перевір IP без порту, приватний профіль мережі, брандмауер і відсутність ізоляції клієнтів.
- Чорний екран: вимкни HDR, обери правильний монітор, спробуй сумісне захоплення та JPEG.
- Помилка зайнятого порту: закрий попередню копію Orbit або зупини в ній сеанс.

Журнал: %LOCALAPPDATA%/OrbitDisplay/orbit.log. У цій папці також зберігається сертифікат ПК. Видалення програми залишає дані спарювання, щоб не втратити довіру пристроїв під час перевстановлення. Android APK видаляється окремо на телефоні; віртуальний драйвер — через Virtual Driver Control.
