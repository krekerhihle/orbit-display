# Історія змін

## 0.4.0 · 2026-10-28

- NVENC з перетворенням RGB на GPU, Quick Sync/x264 як резерв.
- Пропуск незмінених кадрів, 60 FPS в автоматичному режимі.
- Обмежене вікно чотирьох H.264-кадрів для апаратних декодерів.
- Підписані оновлення з GitHub на Windows та Android.
- Українські повідомлення USB без пошкодженого кодування.
